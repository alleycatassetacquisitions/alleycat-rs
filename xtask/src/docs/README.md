# Device API documentation

Edit the definitions and comments under `proto/`, then run with Docker running:

```bash
cargo xtask docs proto
```

Commit the generated `static/device-apis/index.html` alongside the protobuf changes.
The page is generated by [protoc-gen-doc](https://github.com/pseudomuto/protoc-gen-doc)
and served at `/docs/device-apis`. Normal application builds use the committed HTML.

Run `cargo xtask docs proto --check` to check for stale output without rewriting it.
CI runs the same check.
